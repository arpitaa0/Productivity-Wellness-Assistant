# Productivity & Wellness Assistant

A Windows-based Productivity and Wellness Assistant developed in C++ that monitors user activity, tracks study and entertainment time, detects fatigue, and provides productivity recommendations.

## Features

* Real-time activity monitoring
* Study vs Entertainment classification
* Entertainment quota tracking
* Fatigue calculation model
* Dynamic task prioritization
* Idle time detection
* Efficiency score tracking
* CSV activity logging
* Windows notifications and alerts

## Technologies Used

* C++
* STL (Vector, Algorithm, File Handling)
* Windows API
* Object-Oriented Programming

## How It Works

1. Detects the active application window.
2. Classifies activity as Study, Entertainment, or Other.
3. Tracks study and entertainment duration.
4. Calculates fatigue using a mathematical model.
5. Alerts users when entertainment limits are exceeded.
6. Detects prolonged idle time during study sessions.
7. Logs activity data into a CSV file for future analysis.
